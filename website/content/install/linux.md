# Install HARP on Linux

To install HARP on Linux (requires glibc 2.35 or later, _e.g._ Ubuntu 22.04, Debian 12, Fedora 36, or newer):

* Download the archive for your architecture (`x64` or `arm64`) from the [releases](https://github.com/TEAMuP-dev/HARP/releases) page.

* Extract `HARP` from the archive (_e.g._ `tar -xzf HARP-<version>-Linux-x64.tar.gz`).

* Move `HARP` to your chosen location (_e.g._ `/usr/local/bin/`).
